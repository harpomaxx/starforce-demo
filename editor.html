PICO-8 Style Map Editor v1.2

Create 16x32 maps for Star Force. Use continent_piece for basic terrain, and other tiles for interactive bases.

Controls: Left-click to paint, Right-click to erase. Hold and drag to paint continuously.

🎮 Map Editor Controls

🖱️ Mouse Controls:

  • Left Click: Paint selected tile
  • Right Click: Erase tile
  • Drag: Paint/erase continuously

⌨️ Keyboard Shortcuts:

  • Ctrl+S: Export map
  • Ctrl+O: Load map
  • Ctrl+R: Resize map
  • Ctrl+C: Copy selected area
  • Ctrl+V: Paste at center
  • Ctrl+A: Select all
  • Delete: Clear selection/map
  • Escape: Clear selection
  • G: Toggle grid
  • H: Show/hide help

🔲 Selection Mode:

  • Shift + Drag: Select area
  • Click: Clear selection
